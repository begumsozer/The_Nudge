#Here is our final project for the Java Programming course

Our application is named Nudge and run on Java Swim.

First by looking at the structure of our project you should see that we've decided to don't use any RDBMS in this project. And this for good reasons. First at the begining of the project we didn't know how to do and it's just recently that we mastered that technology so we didn't want to take any risk by implementing an unknown technology in our application. Also, if we'd have used a RDBMS, some additionnal manipulation would have been asked to the user to run our program and we wanted something able to be directly runnable by the user.

And talking about that how to run and use our program ? To run it it's simple, you just have to open the repository in any IDE supporting Java language. Then go into the file name NudgeApp.java and click on the little green triangle in the top right corner of your screen and here you are you've just luanch Nudge. Now, you should have our welcome screen in front of you. At that point click on the button saying "Log in or Sign in here" at the bottom of the page. You now should be facing our log in screen and since it's your first time on Nudge you should click on the bottom right button saying "I'm new". Here enter all you're informations and select you're status Student or Requester. Once it's done (you should see a message saying "Account created succefully!") you should be able to log in by filling the text boxes with first your email address and then your status and finally clicking the bottom left button saying "Log in".

Now 2 possibilities:
Either you subscribe as a Requester (which is the best status to start because as a Student you're experience on Nudge depend totally on the requesters) or as a Student (in any case to see the range of possibilities you should create two accounts with two different Status at some point).

In the case of a requester, you'll be able to create some requests and then to see and edit them until a student accept them. Indeed, once a Student would have accepted your request, if you'll still be able to see it, you won't be able to edit it anymore (except if he declines it). In exchange you'll win a new interaction wich is he chat with the student. Finally, 2 last actions are allowed "Delete" and "Mark as Done". For us it won't change anything but if the application would really exist Mark as Done would automatically pay the Student related to the Request. Also, while delete is allowed at any moment, mark as done is only possible when the Request is accepted.

In the case of a student, 2 options will show up. First you'll be able to "Look for Request", when clicking on that button you'll be send to a page with the different parameters caracterizing a request. Those are filters allopwing to be more accuratte in your research. However, you can also directly click on the bottom left button "Search" which will allow you to see all the available existing requests, you'll then be allowed to accept by interacting with them or to not by not interacting with them. Finally, you'll be able to see your list of tasks (accepted requests) and to either decline it or to chat with the requester who posted it.

And that's it for Nudge. Hope you'll enjoy use our application. And don't forget, use Nudge:
